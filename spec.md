# 🚀 Personal Portfolio (Frontend)

A modern, responsive **portfolio web application** built using React.js, designed to showcase projects, skills, and achievements with a clean professional UI.

---

## 📌 Features

* ⚡ Fully responsive design
* 🌙 Dark / Light mode toggle
* 🎨 Smooth animations (Framer Motion)
* 📂 Project showcase with media support
* 📄 Resume download
* 📊 Optional visitor tracking
* 📬 Contact form (UI)

---

## 🧱 Pages

* Home (Hero)
* About
* Skills
* Projects
* Experience
* Achievements
* Contact

---

## 🎯 UI Rules

* 3 cards per row (desktop)
* 1 card per row (mobile)
* Clean and modern layout
* Smooth scrolling navigation
* Sticky navbar with active highlight

---

## ⚙️ Setup & Run Locally

```bash
# Clone the repository
git clone https://github.com/your-username/portfolio.git

# Navigate to project
cd portfolio

# Install dependencies
npm install

# Start development server
npm start
```
